# 버전별 문항표 (라벨러용)

라벨은 아래 '라벨 값' 형식 중 하나 또는 `NONE`이다. 오타를 막으려고 `compare_labels.py`가 허용 값인지 검사한다.

- 선택지 일치: `문항id|option|선택지 문구` (선택지 문구는 표의 글자 그대로)
- 그 문항에 답함: `문항id|answered`
- 그 문항을 비움: `문항id|unanswered`
- 그 버전에서 매칭 불가: `NONE`

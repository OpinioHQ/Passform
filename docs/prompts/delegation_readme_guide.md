## 사람이 정한 것

- 접속 주소 https://app.passform.kr (백엔드 https://api.passform.kr), 저장소 https://github.com/OpinioHQ/Passform `main`.
- 2팀, Opinio(오피니오), 서비스 Passform.
- 예시 폼은 동아리 지원서. 문항은 에이전트 초안(이름·학과·학년·연락 이메일 / 지원 분야·면접 가능 시간·지원 동기·동아리에 바라는 점, AI 요약 사용·제출 후 수정 허용)대로 사람이 배포 서버에서 만들었다. 링크 https://app.passform.kr/f/Ui3ECL00PybHgYe4zrbzBA.
- 체험은 응답자(로그인 없이·로그인해서)와 제작자(만들기·배포 → 응답 → 결과·AI 결과 탐색) 두 역할. 결과·탐색은 제작자만 본다는 것을 한 줄로 알린다.
- AI 결과 탐색 예시 질문은 실제로 통과한 유형만(조건 개수, 전체 요약, 문항 요약, 특정 의견 요약, 조건+문항 요약, `delegation_ai_summary.md` "E8 뒤 마무리" 표). 빈도 질문은 쓰지 않고 제한 절에 "되물을 수 있음"으로만 적는다.
- 테스트 계정은 주지 않는다. 실제 개인정보를 넣지 말라는 경고를 눈에 띄게 둔다.
- 가이드 위치는 팀원 소개 뒤, GitHub 절 앞. 로그아웃이 없으니 다른 계정은 시크릿 창으로 안내한다.
- `frontend/README.md` 37행을 지금 상태(가짜 데이터는 `VITE_USE_API=false`일 때만)로 한 줄 고친다(사람 승인, 이 이슈 범위 밖 파일).
- 휴대폰 Safari 응답은 사람이 배포 주소에서 확인했다(됨). 지원 환경에 반영했다.
- 개인정보처리방침 링크 https://app.passform.kr/privacy.html 을 2절에 넣는다(PR #103 머지 뒤 열림).
- **임시:** Google 로그인이 아직 테스트 상태라 2절에 "로그인이 막히면 문의처로 Gmail 주소를 알려 달라"는 한 줄을 넣었다. Google 로그인을 프로덕션으로 게시하면 이 줄을 지운다.

1. 초안 작성(2026-11-09). 화면 문구는 `frontend/src` 코드에서, 로그인 필요 여부는 SPEC 5절 인증 열과 `SecurityConfig`에서, OpenAI 키 없을 때 동작은 `OpenAiQueryParser`·`exploreView.ts`의 503 안내로 확인했다. 로컬 실행은 `AGENTS.md` 7절, `.env.example`, `frontend/.env.example`, `docker-compose.yml`, `application.properties`와 맞췄다.

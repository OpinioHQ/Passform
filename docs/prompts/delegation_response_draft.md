## §1 결함 주입

하나씩 임시로 넣고 되돌렸다. 백엔드는 `gradlew test --tests '*ResponseDraft*'`(실제 Postgres)를 돌리기 전에 `build/test-results/test/*.xml`을 지우고, 새로 생긴 XML에서 기대한 테스트가 실행됐고(skip 아님) 실패했는지 봤다. 프런트는 `vitest run --reporter=json` 결과로 봤다. 주입 전후 `git diff --stat`이 같은 것을 확인했다. 주입은 커밋하지 않았다.

| 질문 | 답 |

에이전트가 SPEC 안에서 정한 것:

- `GET .../response-draft`의 `form_definition`은 작성 시작 버전을 공개 조회(`GET /f/{slug}`)와 같은 모양으로 준다(`PublicFormService.viewOfVersion`). 마감은 보지 않고 운영 설정은 현재 값이다.
- `PUT`의 판정 순서는 제출과 같다: 없는 폼 → 버전 → 닫힘. 최신 버전이 아니거나 저장된 초안이 옛 버전이면 `409 form_version_changed`다. 옛 초안은 지운 뒤 새로 시작한다.
- 값 모양(문자열, 문자열 배열, null)만 보고 그 밖은 `400 invalid_request`다. 필수·형식·선택지·분기는 보지 않는다(SPEC 207행).
- 같은 사용자의 초안 저장은 `users` 행을 잠가 한 번에 하나씩 처리한다(폼당 한 건, 동시 첫 저장에도 500 없음). 초안 제출은 그 응답 행을 잠근다.
- `DELETE`는 초안이 없어도 204다. 내 폼함 항목과 제출 응답은 지우지 않는다.
- 제출의 `draft_response_id`가 본인의 작성 중 응답이 아니면(남의 것, 제출된 것, 다른 폼, 비로그인) `404`다(SPEC 188행). 초안의 버전이 제출 버전과 다르면 `409 form_version_changed`다.
- 409 `form_version_changed` 뒤 "최신 폼 다시 열기"는 옛 초안을 지우고 다시 연다(T4 결정 "답을 비우고 새로 시작"). T4 테스트는 그대로 통과한다.
- 응답자가 직접 지우는 "작성한 답 지우기"를 두었다(SPEC 208행).
- `api.me`는 한 페이지에서 `/me`를 한 번만 부른다. 헤더와 응답 화면이 같은 결과를 쓴다. 앱 안에 로그아웃이 없고 로그인은 전체 페이지 이동이다.

시험 폼: T4 때 개발 DB에 넣은 폼 B(분기 없는 한 질문씩, 버전 2). 서버는 작업 폴더의 이 브랜치 코드로 띄웠다.

| 확인 | 결과 |
|---|---|
| 1. 로그인: 작성 → "계정에 저장됨" → 새로고침 복원 → 다른 브라우저에서 같은 계정으로 복원 | 됨. DB에 IN_PROGRESS 초안 1건(버전 2, 답 3개), 내 폼함 `SAVED` 1건 |
| 2. 비로그인: 같은 브라우저 새로고침 복원, 다른 브라우저에는 초안 없음 | 됨 |
| 3. B를 버전 3으로 올린 뒤 옛 초안 | 됨. 이전 버전 안내와 저장된 답이 보이고 "기존 답 지우고 새로 시작"으로 빈 폼. DB에서 옛 초안이 지워짐 |
| 4. 다시 작성해 자동 저장 뒤 제출 | 됨. DB의 버전 3 응답이 `saved_at`(자동 저장)과 `submitted_at`을 함께 가진 한 행이다. 초안 없이 새로 제출한 응답은 `saved_at`이 비어 있으므로, 자동 저장한 초안 행이 같은 `response_id`로 `SUBMITTED`가 됐다. 남은 초안 0건 |

- DB 확인은 에이전트가 응답 ID, 상태, 버전, 시각 유무, 답 개수만 봤다. 답 값은 출력하지 않았다.
- 모바일 브라우저 복원(AC82 테스트 줄)은 이번에 확인하지 않았다.

## §7 알려진 한계

- 앱 안의 메뉴 이동은 브라우저 경고로 막지 못한다(라우터가 데이터 라우터가 아니다). 대신 화면을 떠날 때 기다리던 저장을 바로 보낸다. 새로고침·창 닫기는 경고한다.
- 제출할 때 내 폼함 항목을 `submitted`로 바꾸는 일(AC17 "저장 없이 제출 → submitted")은 하지 않았다. 초안을 제출하면 항목은 `saved`로 남는다. E5가 `GET /me/forms`와 함께 다룬다.
- `409 storage_quota_exceeded`는 용량 계산이 아직 없어 반환하지 않는다.
- 비로그인 초안의 브라우저 저장은 기한이 없다. 지우는 때는 제출 성공, "작성한 답 지우기", 옛 버전에서 새로 시작할 때다. 폼 삭제를 확인할 때 지우는 일(SPEC 208행)은 T12 범위다.
- **미룸(PR #85 리뷰 3번):** 로그인 전에 쓴 브라우저 초안이 옛 버전이면 로그인 뒤 안내 없이 빈 폼이 열린다(브라우저 초안은 남아 있다). 드문 경우라 11/11 전에는 고치지 않는다.
